# Scraper Service

V2/V3 acquisition layer. It will support approved public and explicitly authorized sources, HTTP fetching, permitted browser rendering, parsers, OCR/document extraction, source policies, rate limiting, retries, source health, evidence provenance, hashing, and job orchestration.

It must never bypass authentication, CAPTCHAs, access controls, robots/rate limits, private accounts, leaked databases, or covert tracking.
